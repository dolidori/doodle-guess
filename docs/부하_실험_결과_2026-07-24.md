# Doodle Guess 장시간 부하 실험 결과

## 실행 환경과 시나리오

- 실행일: 2026-07-24
- 환경: macOS arm64, 논리 CPU 10개, 메모리 16GiB, Node.js v24.12.0
- 서버: 단일 Node 프로세스, 인메모리 Room Map, `perMessageDeflate=false`
- 기준 부하: 20개 방 × 방당 30연결 = 600연결, 30분
- 스트레스 부하: 50개 방 × 방당 30연결 = 1,500연결, 30분
- 각 방 구성: k6 정상 연결 29개 + Node 느린 수신자 1개
- 느린 수신자: 5분 후부터 20초 수신 정지·5초 복구 반복
- 트래픽: drawer 20 stroke batch/초, 참여자 오답 burst와 정답 경합, 반복 라운드

테스트 Mac의 절전으로 이벤트 루프가 약 244.7초 멈춘 첫 600연결 시도는 heartbeat가 일괄 만료되어 무효 처리했다. 절전 방지 후 두 시나리오를 처음부터 다시 실행했다.

## 판정

- 1,500연결 스트레스 부하는 모든 정합성·지연·서버 자원 기준을 통과했다.
- 600연결 기준 부하는 정합성·지연·CPU·이벤트 루프·큐 기준을 통과했지만 RSS가 222.1MB에서 244.8MB로 +10.24% 증가해 `<10%` 기준을 0.24%p 초과했다.
- 따라서 전체 부하 게이트는 **메모리 기준 1건 미충족**이다. 더 높은 1,500연결에서 RSS가 감소한 점을 보면 단조 증가 누수로 단정할 근거는 없지만, 단일 시점의 측정값을 임의로 합격 처리하지 않는다.
