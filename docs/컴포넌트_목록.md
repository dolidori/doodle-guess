# Doodle Guess React 컴포넌트 목록

## 1. 공통 TypeScript 계약

화면 컴포넌트는 WebSocket을 직접 참조하지 않는다. `GameProvider`가 서버 이벤트를 reducer 액션으로 바꾸고, 컨테이너가 검증된 intent 콜백을 전달한다.

```ts
export type RoomMode = 'NORMAL' | 'MODERATOR';
export type RoundPhase =
  | 'PREPARING_KEYWORD'
  | 'DRAWING_AND_GUESSING'
  | 'SOLVED'
  | 'EXPIRED';
export type ConnectionStatus = 'CONNECTING' | 'CONNECTED' | 'RECONNECTING' | 'FAILED';
export type DrawingTool = 'PEN' | 'ERASER';
export type StrokeWidth = 'THIN' | 'MEDIUM' | 'THICK';
export type PenColor =
  | 'BLACK'
  | 'BLUE'
  | 'ORANGE'
  | 'GREEN'
  | 'VERMILION'
  | 'PURPLE';

export type AllowedAction =
  | 'SET_ROUND_DURATION'
  | 'SET_KEYWORD_AND_START'
  | 'DRAW_STROKE_BATCH'
  | 'UNDO_LAST_STROKE'
  | 'CLEAR_DRAWING'
  | 'SUBMIT_GUESS'
  | 'ASSIGN_DRAWER'
  | 'RECLAIM_DRAWER'
  | 'KICK_PLAYER'
  | 'START_NEXT_ROUND'
  | 'LEAVE_ROOM';

export interface PlayerView {
  playerId: string;
  nickname: string;
  connected: boolean;
  isHost: boolean;
  isModerator: boolean;
  isDrawer: boolean;
}

export interface GuessFeedItem {
  guessId: string;
  roundId: string;
  guessSeq: number;
  playerId: string;
  nickname: string;
  text: string;
  submittedAt: number;
  isCorrect: boolean;
}

export interface NormalizedPoint {
  x: number;
  y: number;
}

export interface StrokeBatchIntent {
  roundId: string;
  drawingRevision: number;
  drawerEpoch: number;
  strokeId: string;
  batchSeq: number;
  tool?: DrawingTool;
  color?: PenColor;
  width?: StrokeWidth;
  points: readonly NormalizedPoint[];
  isFinal: boolean;
}

export interface DrawingSnapshot {
  roundId: string;
  drawingRevision: number;
  lastDrawingSeq: number;
  strokes: readonly ServerStroke[];
}

export interface ServerStroke {
  strokeId: string;
  authorId: string;
  tool: DrawingTool;
  color: PenColor;
  width: StrokeWidth;
  points: readonly NormalizedPoint[];
}

export interface KeywordPrivateView {
  roundId: string;
  keyword: string;
}

export interface SolvedView {
  eventId: string;
  roundId: string;
  guessId: string;
  guessSeq: number;
  winnerId: string;
  winnerNickname: string;
  solvedAt: number;
}

export interface HostAbsenceView {
  hostId: string;
  hostDisconnectedAt: number;
  expiresAt: number;
}

export interface RoundTimingView {
  durationSeconds: number;
  roundEndsAt: number | null;
  serverEpochAtAnchor: number | null;
  localMonotonicAtAnchor: number | null;
}

export interface ExpiredView {
  eventId: string;
  roundId: string;
  expiredAt: number;
  roundEndsAt: number;
}

export type ClientIntent =
  | { type: 'CREATE_ROOM'; nickname: string; mode: RoomMode }
  | { type: 'JOIN_ROOM'; roomCode: string; nickname: string; sessionToken?: string }
  | { type: 'SET_ROUND_DURATION'; durationSeconds: number }
  | { type: 'SET_KEYWORD_AND_START'; roundId: string; keyword: string }
  | { type: 'DRAW_STROKE_BATCH'; batch: StrokeBatchIntent }
  | {
      type: 'UNDO_LAST_STROKE';
      roundId: string;
      drawingRevision: number;
      drawerEpoch: number;
    }
  | {
      type: 'CLEAR_DRAWING';
      roundId: string;
      drawingRevision: number;
      drawerEpoch: number;
    }
  | { type: 'SUBMIT_GUESS'; roundId: string; guessId: string; text: string }
  | { type: 'ASSIGN_DRAWER'; targetPlayerId: string }
  | { type: 'RECLAIM_DRAWER' }
  | { type: 'KICK_PLAYER'; targetPlayerId: string }
  | { type: 'START_NEXT_ROUND'; previousRoundId: string }
  | { type: 'LEAVE_ROOM' };

export type DispatchIntent = (intent: ClientIntent) => void;
```

실제 이벤트 payload의 필드 제한과 최대 크기는 `WebSocket_이벤트_명세.md`를 따른다. UI는 `AllowedAction`을 추가로 만들거나 서버 상태를 낙관적으로 바꾸지 않는다.

[근거: 공통 지침 §1.2·§3.7·§4.8, 결정 D-06·D-10·D-13]

## 5. 제시어

### `KeywordSetupForm`

```ts
export interface KeywordSetupFormProps {
  canStart: boolean;
  disabledReason: string | null;
  submitting: boolean;
  onSubmit: (keyword: string) => void;
}
```

- `제시어 확정 및 시작` 단일 제출을 제공한다.
- 제출 응답 전 중복 제출을 막되 라운드 상태는 낙관적으로 변경하지 않는다.

### `RoundDurationControl`

```ts
export interface RoundDurationControlProps {
  valueSeconds: number;
  disabled: boolean;
  disabledReason: string | null;
  onCommit: (durationSeconds: number) => void;
}
```

- native `input type="range"`에 이름 `제한 시간`, `min={20}`, `max={180}`, `step={5}`를 사용한다.
- 현재값은 `1분 30초` 형식으로 슬라이더 옆에 표시하고 동일한 문자열을 `aria-valuetext`로 제공한다.
- 기본값은 60초이며 Arrow 키는 native range 동작에 따라 5초씩 이동한다.
- 드래그 중 값은 컴포넌트 로컬 draft로만 미리 표시하고 pointer up·blur 또는 300ms 키보드 debounce 뒤 마지막 값 한 건을 `onCommit`한다. 서버 PUBLIC 값이 오면 draft를 확정값에 맞춘다.
- slider track을 포함한 조작 영역은 높이 44 CSS px 이상이다.
- `PREPARING_KEYWORD`가 아니면 disabled와 `라운드 진행 중에는 제한 시간을 바꿀 수 없습니다`를 함께 표시한다.
- `SET_ROUND_DURATION`이 없는 위임 drawer와 일반 참여자에게는 `RoundDurationReadout`만 표시한다.

### `RoundDurationReadout`

- 설정된 값을 자연어로 표시하며 변경 조작은 만들지 않는다.

### `RoundTimer`

```ts
export interface RoundTimerProps {
  phase: RoundPhase;
  timing: RoundTimingView;
  hasAnnouncedTenSecondWarning: boolean;
  onTenSecondThreshold: () => void;
}
```

- `serverEpochAtAnchor + (performance.now() - localMonotonicAtAnchor)`로 서버 현재 시각을 추정하고 `roundEndsAt`과의 차이를 0 이상으로 잘라 `MM:SS`로 표시한다.
- 초 표시는 모든 역할 화면에서 `Math.ceil(remainingMs/1000)`으로 통일한다.
- 표시 scheduler는 상위 provider에 하나만 두고, 이 컴포넌트 인스턴스마다 독립 interval을 만들지 않는다.
- 10초 이하에 처음 진입할 때만 `onTenSecondThreshold`를 호출한다.
- 클라이언트 0초 도달은 화면을 `00:00`으로만 만들며 `ROUND_EXPIRED`를 생성하지 않는다.
- `visibilitychange` 후 서버 시간을 다시 동기화하고 즉시 시간을 계산한다.


- `GameHeader`의 브랜드, `RoomCodeModal`, `RoundSolvedModal`, `RoundExpiredModal`, 큰 주요 버튼은 `"Jua", "LINE Seed Sans KR", "Arial Rounded MT Bold", "Apple SD Gothic Neo", system-ui, sans-serif`를 사용한다.
- `KeywordSetupForm`, `KeywordPanel`, `GuessComposer`, `GuessFeed`, 참가자 이름, timer, 작은 본문과 버튼은 `"LINE Seed Sans KR", "Arial Rounded MT Bold", "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif`를 사용한다.

- 폰트 파일 로딩 실패 시 fallback이 즉시 표시되며 모든 폼의 모바일 글자 크기는 16px 이상을 유지한다.
