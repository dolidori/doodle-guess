# Doodle Guess 디자인시스템

## 1. 시각 방향

Doodle Guess는 기존 아이콘의 보라·인디고 배경, 노랑 강조, 흰 스케치북, 짙은 잉크를 이어가는 밝고 장난스러운 스케치북 테마다. 캔버스는 가장 밝고 큰 면으로 유지하고 주변 UI는 보라 계열로 묶는다.

- 귀여움은 둥근 글꼴·모서리·간결한 일러스트로 표현한다.
- 입력 가독성을 해치는 과도한 손글씨체는 사용하지 않는다.
- 상태는 색상 하나에 의존하지 않고 텍스트·아이콘·테두리 스타일을 함께 사용한다.
- UI 텍스트에 이모지를 사용하지 않는다.

[근거: 결정 D-19, 대표님 추가 결정 — 둥글고 귀여운 글씨체]

### 2.1 의미 규칙

| 상태 | 색 | 동반 표현 |
|---|---|---|
| 현재 drawer | 노랑 강조 | `그리기` 배지, 굵은 실선 |
| 추측 가능 | 청록·파랑 계열 | `추측 가능` 문구 |
| 해결 | 성공 녹색 | `정답 확정` 문구와 체크 아이콘 |
| 시간 10초 이하 | 경고 주황 | `시간 얼마 남지 않음`, 시계 아이콘, 굵은 테두리 |
| 시간 종료 | 중립 보라·회색 | `시간 종료`, `00:00`, 시계 아이콘 |
| 연결 끊김 | 위험 빨강 | `연결 끊김` 문구와 끊어진 연결 아이콘 |

일반 본문 대비는 4.5:1 이상, 큰 글자와 UI 경계는 3:1 이상을 유지한다. 팔레트 구현 후 자동 대비 검사와 실제 모바일 화면 검사를 모두 수행한다.

## 3. 고정 접근성 드로잉 팔레트

자유 색상 선택기는 제공하지 않는다. 서버와 클라이언트가 아래 6색만 허용한다.

| enum | 라벨 | HEX | 캔버스 위 용도 |
|---|---|---:|---|
| `BLACK` | 검정 | `#111827` | 기본값, 윤곽 |
| `BLUE` | 파랑 | `#0072B2` | 차가운 강조 |
| `ORANGE` | 주황 | `#E69F00` | 밝고 따뜻한 표현 |
| `GREEN` | 초록 | `#009E73` | 자연물 |
| `VERMILION` | 주홍 | `#D55E00` | 강한 따뜻한 강조 |
| `PURPLE` | 보라 | `#7B2CBF` | 보라 계열 표현 |

- 모든 색은 서버·클라이언트가 공유하는 고정값이다. 주황처럼 명도가 높은 견본 버튼에는 짙은 외곽선을 더해 흰 UI 표면과 경계를 확보한다.
- 색상 버튼은 원형 견본과 한국어 라벨 또는 접근성 이름을 함께 가진다.
- 현재 색은 굵은 이중 테두리, 체크 아이콘, `aria-pressed="true"`로 표시한다.
- 색맹 사용자가 게임 상태를 판단해야 하는 용도로 드로잉 색상을 사용하지 않는다.
- 지우개는 흰 펜이 아니라 `ERASER` tool로 구분해 벡터 동기화 의미를 보존한다.

## 4. 펜 굵기와 도구

| enum | UI 라벨 | 정규화 굵기 |
|---|---|---:|
| `THIN` | 얇게 | `0.003` |
| `MEDIUM` | 보통 | `0.007` |
| `THICK` | 굵게 | `0.014` |

정규화 굵기는 캔버스의 짧은 변을 기준으로 렌더링한다. 화면 축소 시에도 최소 1 CSS px 이상 보이게 한다.

- 도구: 펜, 지우개
- 편집: 마지막 서버 확정 스트로크 되돌리기, 전체 지우기
- 전체 지우기: 확인 모달 뒤 서버 성공으로만 반영
- drawer 권한 상실, 정답 확정, 시간 종료에는 모든 도구를 즉시 비활성화
- 도구 버튼은 44×44 CSS px 이상이며 아이콘과 텍스트 접근성 이름을 함께 제공

## 5. 타이포그래피

### 5.1 폰트 family

| 용도 | family | weight |
|---|---|---|
| 게임명, 화면 제목, 방번호 확대, 정답·시간 종료 모달 제목, 큰 주요 버튼 | `Jua` | 400 |
| 제시어, 추측 입력·피드, 참가자 이름, 본문, 작은 버튼, 카운트다운 | `LINE Seed Sans KR` | 400, 700 |

```css
@font-face {
  font-family: "Jua";
  src: url("/fonts/jua-regular.woff2") format("woff2");
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}

@font-face {
  font-family: "LINE Seed Sans KR";
  src: url("/fonts/line-seed-sans-kr-regular.woff2") format("woff2");
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}

@font-face {
  font-family: "LINE Seed Sans KR";
  src: url("/fonts/line-seed-sans-kr-bold.woff2") format("woff2");
  font-style: normal;
  font-weight: 700;
  font-display: swap;
}

:root {
  --font-display: "Jua", "LINE Seed Sans KR", "Arial Rounded MT Bold",
    "Apple SD Gothic Neo", system-ui, sans-serif;
  --font-body: "LINE Seed Sans KR", "Arial Rounded MT Bold",
    "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif;
}
```

- Jua는 20px 미만 텍스트, 제시어·추측 입력값, 긴 본문, 참가자 닉네임, 카운트다운에 사용하지 않는다.
- 한글·영문·숫자가 섞인 입력은 LINE Seed Sans KR 하나로 렌더해 자폭과 기준선을 안정화한다.
- 숫자 카운트다운은 LINE Seed Sans KR 700과 `font-variant-numeric: tabular-nums`를 사용한다.
- WOFF2 파일은 앱과 함께 자체 호스팅하며 외부 CDN을 런타임 의존성으로 두지 않는다.
- LINE Seed Sans KR의 SIL OFL 1.1 파일과 공식 출처 표기를 저장소 `client/public/fonts/licenses/LINE-SEED-SANS-KR-OFL.txt` 및 앱 도움말·라이선스 문서에 보관한다.
- Jua의 Google Fonts 배포 OFL 파일을 `client/public/fonts/licenses/JUA-OFL.txt`에 폰트 파일과 함께 보관한다.
- 폰트 로딩 실패 시 위 시스템 둥근 고딕 fallback을 사용하며 레이아웃과 기능은 그대로 유지한다.

## 7. 버튼과 입력

### 7.1 버튼

| variant | 용도 |
|---|---|
| `primary` | 입장, 제시어 확정 및 시작, 다음 라운드 |
| `secondary` | drawer 지정·회수, 제시어 보기 |
| `danger` | 강퇴, 방 나가기, 전체 지우기 확인 |
| `ghost` | 모달 닫기, 보조 조작 |

- native `disabled`를 사용하고 opacity만으로 상태를 만들지 않는다.
- 비활성 버튼 옆 또는 `aria-describedby` 대상에 이유를 표시한다.
- hover는 2px 이내 이동, active는 눌림 그림자, focus-visible은 3px 노랑 outline을 사용한다.

### 7.2 텍스트 입력

- 입력 font는 LINE Seed Sans KR 16px 이상이다.
- 제시어와 추측은 한 줄 input을 사용한다.
- 오류는 입력 아래 텍스트와 `aria-describedby`로 연결한다.
- 서버 거부 시 값을 유지하고 서버 수락 시에만 비운다.
- placeholder만 label 역할을 하지 않는다.

### 7.3 제한 시간 range input

```html
<label for="round-duration">제한 시간</label>
<input
  id="round-duration"
  name="round-duration"
  type="range"
  min="20"
  max="180"
  step="5"
  value="60"
  aria-valuetext="1분"
/>
<output for="round-duration">1분</output>
```

- 기본값은 60초, 범위는 20~180초, 간격은 5초다.
- 현재값은 `20초`, `1분`, `1분 30초`, `3분`처럼 자연어로 표시한다.
- Arrow 키로 5초씩 이동하고 native range의 Home·End 동작을 유지한다.
- 드래그 중에는 자연어 값을 로컬 미리보기하고 pointer up·blur 또는 300ms 키보드 debounce 뒤 마지막 값 한 건만 서버에 보낸다.
- track과 thumb를 포함한 전체 조작 높이는 44px 이상이다.
- 라운드 진행 중에는 disabled이며 `라운드 진행 중에는 제한 시간을 바꿀 수 없습니다`를 항상 표시한다.
- 위임 drawer와 추측자에게는 값만 읽기 전용으로 표시한다.

## 8. 카운트다운

- 서버 `roundEndsAt`와 왕복 시간 보정·단조 시계 anchor로 동기화한 서버 시각을 사용해 `MM:SS`를 표시한다.
- 기본 상태는 흰 숫자와 얇은 진행선이다.
- 10초 이하 최초 진입 시 경고 아이콘, `시간 얼마 남지 않음`, 굵은 주황 테두리를 표시하고 `aria-live="assertive"`로 `10초 남았습니다`를 한 번 알린다.
- 이후 매초를 음성으로 읽지 않는다.
- 0초 화면은 `00:00`을 유지하고 서버 `ROUND_EXPIRED`가 와야 입력·그림을 잠근다.
- 백그라운드 복귀 시 서버 시간을 다시 동기화하고 애니메이션으로 따라잡지 않은 채 즉시 실제 남은 값으로 바꾼다.
- `prefers-reduced-motion`에서는 프로그레스 전환 애니메이션을 제거한다.

[근거: 대표님 추가 결정 — 라운드 제한 시간, 공통 지침 §4.9·§5.4]

## 9. 제시어 정보 표현

- PRIVATE 제시어 패널은 권한자에게만 렌더한다.
- 기본 상태는 `제시어가 가려졌습니다`와 `제시어 보기` 버튼이다.
- 공개 시 label `제시어`, 원문, `제시어 가리기` 버튼을 표시한다.
- 마스킹 문자로 글자 수를 드러내지 않는다.
- 보기 상태는 로컬이며 재접속, 새 라운드, 열람 권한 획득 때마다 가림으로 시작한다.
- 열람 권한 상실 시 패널을 단순 숨김 처리하지 않고 PRIVATE 문자열을 상태에서 삭제한다.

[근거: 게임 설명 7~8행, 결정 D-11]

## 10. 공개 추측 피드

- 행 구성은 순번, 닉네임, 추측 내용이다.
- 추측 내용은 LINE Seed Sans KR로 렌더하며 줄바꿈은 단어 단위로 허용한다.
- 본인 추측은 `내 추측` 보조 라벨로 표시한다.
- 정답 추측은 `정답` 텍스트 배지, 굵은 테두리, 성공 아이콘을 함께 사용한다.
- 피드 배경은 surface, 각 행은 색 대비가 있는 교대 surface를 사용한다.
- 사용자가 과거 항목을 읽는 동안 자동 스크롤하지 않고 `새 추측 N개` 버튼을 제공한다.
- 수락되지 않은 요청과 PRIVATE 제시어는 피드에 넣지 않는다.

[근거: 결정 D-10]

## 11. 모달·토스트·오버레이

### 11.1 모달

- 너비: `min(92vw, 28rem)`
- padding: `clamp(1.5rem, 4vmin, 2.5rem)`
- 제목은 Jua, 본문은 LINE Seed Sans KR
- 정답자 모달: 성공 아이콘, `정답을 맞혔습니다`, 닉네임
- 시간 종료 모달: 시계 아이콘, `시간 종료`, `제한 시간이 끝났습니다`
- 두 결과 모달은 `roundId`별 고유 키로 각각 한 번만 표시한다.
- 모달을 닫아도 결과 배너는 유지한다.

### 11.2 토스트

- 권한 변경, 재접속 성공, 서버 거부 같은 비차단 정보만 사용한다.
- FIFO, 동시에 최대 3개, 기본 약 2초다.
- 오류는 사용자가 읽을 수 있게 4초까지 유지한다.
- 배경 없이 큰 글씨만 사용하는 단순 토스트에도 스크린 리더 메시지를 제공한다.

### 11.3 차단 오버레이

- 재접속, 강퇴, 호스트 30분 미복귀 종료, 서버 재시작 후 방 없음에 사용한다.
- 배경 canvas와 PRIVATE 내용을 blur가 아니라 불투명 surface로 덮어 정보 노출을 막는다.
- z-index는 1000이며 포커스는 오버레이 내부에 둔다.

[근거: 결정 D-14·D-17·D-18, 공통 지침 §4.6·§5.4]

| `0~640px` 세로 | 헤더, 캔버스, 역할 조작의 세로 흐름. 참가자·피드는 탭 보조 패널 |
| 높이 `500px` 이하 가로 | 참가자 축약 패널·캔버스·역할 조작의 3영역 |
| `641~1023px` | 캔버스+역할 2열, 참가자·피드 접이식 |
| `1024px` 이상 | 참가자·캔버스·역할/피드 3열 |

- 하단 입력은 `padding-bottom: max(var(--space-3), var(--safe-bottom))`을 사용한다.
- 가상 키보드는 `visualViewport.height`를 반영해 추측 입력을 가리지 않는다.
- 캔버스 이외 영역에서는 pinch zoom을 CSS로 차단하지 않는다.
- 내부 스크롤은 공개 추측 피드와 참가자 목록에만 허용한다.

[근거: `PLANNING_PROMPT` UI/UX 원칙, 공통 지침 §4.3~§4.5·§4.11]

## 14. PWA와 아이콘

### 14.1 기존 에셋

| 파일 | 규격 | 사용 |
|---|---:|---|
| `images/icon/icon-192.png` | 192×192 RGBA PNG | 일반 PWA 아이콘 |
| `images/icon/icon-512.png` | 512×512 RGBA PNG | 고해상도 일반 아이콘·스플래시 원본 |

기존 이미지는 보라 배경, Doodle Guess 글자, 스케치북·전구·연필 도안으로 D-19 테마와 일치한다. 글자와 도안이 가장자리에 가까워 maskable 용도로 직접 지정하지 않는다.

### 14.2 maskable 처리

- `icon-512.png`의 보라 배경을 512×512 전체로 확장한다.
- 핵심 글자·스케치북·연필 도안을 중앙 60% 영역 안으로 비례 축소한다.
- 새 파일 `icon-512-maskable.png`을 만들고 manifest에 `purpose: "maskable"`로만 등록한다.
- 원본 192·512 파일은 `purpose: "any"`로 등록한다.
- 180×180 `apple-touch-icon.png`은 안전 여백을 둔 maskable 구성을 기반으로 만든다.
- Android 원형·스쿼클, iOS 홈 화면, 밝고 어두운 배경의 설치 미리보기에서 잘림을 확인한다.

### 14.3 manifest

```json
{
  "name": "Doodle Guess",
  "short_name": "Doodle Guess",
  "display": "standalone",
  "orientation": "any",
  "theme_color": "#2b1b69",
  "background_color": "#1d1247"
}
```

- 서비스워커는 앱 셸과 정적 에셋만 캐시한다.
- 진행 중 업데이트로 페이지를 자동 새로고침하지 않는다.
- 오프라인에서는 로비 폼을 보여도 서버 액션을 비활성화하고 연결 상태를 명시한다.
